# Gr8coolmind

Desarrollo herramientas para simplificar tareas cotidianas, con proyectos de aplicaciones móviles, utilidades web y redes.

## Proyecto actual

**[USB Tethering Pro](https://github.com/Gr8coolmind/USBTetheringPro)** — Aplicación Android con React Native, TypeScript y un módulo nativo en Kotlin. Facilita el acceso a los ajustes de anclaje USB y guía la conexión del teléfono al ordenador. Actualmente trabajo en su rediseño y en mejorar la experiencia de conexión.

## Otros proyectos

- **[Convertidor de formatos](https://github.com/Gr8coolmind/convertidor-formatos)** — Proyecto de conversión de imágenes, audio, vídeo, documentos y datos con interfaz web.
- **[Arquitectura de red bancaria](https://github.com/Gr8coolmind/grupo3-arquitectura-red-banco)** — Proyecto académico en grupo sobre arquitectura de redes y ciberseguridad.

## Tecnologías presentes en mis proyectos
